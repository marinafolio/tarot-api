# Introduction

The **Tarot API** is a REST API that provides tarot card information and generates randomized tarot readings. Developers can use it to integrate tarot cards and readings into websites, applications, and other software projects.

The API includes all 78 cards in a traditional tarot deck and supports one-card and three-card readings, with optional reversed card orientations.

Requests are made over HTTPS, and responses are returned in JSON format. The API is publicly accessible and does not require authentication.
